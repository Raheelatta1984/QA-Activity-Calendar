# Archived enhancement handovers

This directory is the completion vault for `lib/future-enhancements/ENH-*.md` handovers. A handover is moved here, with `status: "Building"` changed to `status: "Archived"`, only after its linked implementation PR has merged into `main` and its successful `Build and test` check has been verified.

Files here are historical records, not active development requests. The completion workflow closes the linked `arena-handover` development request and preserves unrelated branches. The application's SQLite enhancement status is not synchronised by this Git-side workflow.
